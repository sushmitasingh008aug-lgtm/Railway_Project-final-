# ABPS Delhi–Howrah 15K Data Pack

## Scope
Synthetic application-validation data for the Delhi–Howrah planning corridor covering **2026-09-15 through 2026-12-15**. The route is modeled as six parent planning sections requested by the project, with explicit route variants `MAIN_LINE`, `GRAND_CHORD`, and `HB_CHORD`. Both `UP` and `DOWN` line directions are represented.

## Important data semantics
- Master route structure is represented by six canonical parent section IDs; 15,000-row section/corridor files are **planning observations/snapshots**, not 15,000 distinct railway corridors or sections.
- Historical failure/defect/inspection/maintenance records extend before the planning start so that ML feature windows can be computed without leakage. Planning and forecast records are constrained to the requested date span.
- All generated records are synthetic. They must not be presented as live COA/NTES/UIMS/TMS/TDMS/SMMS data or as official railway operational authority.
- Station anchors are public-reference coordinates; intermediate asset/route points are interpolated synthetic GIS points with a `coordinate_quality` field.

## Public reference basis
Indian Railways published static train lists used only to anchor named service templates: Rajdhani list and Mail/Express list; Jan Shatabdi list. DDU/ECR public information supports Grand Chord context. Station coordinates use public reference points; coordinate precision should be revalidated before any real operational use.
